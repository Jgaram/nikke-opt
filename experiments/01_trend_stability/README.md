# 사전 실험 1 — 경향 안정성

> 보스가 바뀔 때, 과거 랭커 데이터가 "이번 시즌에 무엇이 쓰일지"를 얼마나 맞히나?
> → 이 레포가 랭커 데이터를 **사전 지식으로 얼마나 믿어도 되는지** 정한다.

## 조건

| | |
|---|---|
| 데이터 | `Jgaram/nikke-analysis` @ `4c9bec4` (2026-09-30), 솔로 레이드 시즌 1–40(최종 집계만), 6개 서버 상위 약 300명 × 5덱, 시즌당 약 1,470덱 |
| 쓰는 것 | 사용 여부 · 같은 덱 동반 · 5인 구성 · 버스트 구성. **딜 수치는 쓰지 않는다** |
| 평가 | 시즌 4–40의 각 시즌 t를, t 이전 시즌만으로 예측 (37회) |
| 재현 | nikke-analysis에서 `pip install -e . && nikke build raids` (raid_entries.csv 생성) → `python analyze.py <nikke-analysis 경로>` (pandas, tabulate) |
| 원출력 | [`results.txt`](results.txt) |

예측(사전 지식) 후보:

- 직전 시즌 / 최근 3시즌 평균 / 누적 감쇠 평균(0.8)
- 같은 약점 속성의 직전 시즌
- **혼합** = ½·최근 3시즌 + ½·같은 약점 속성 직전

지표(실제 상위 k = 그 시즌 주력):

- **topk**: 예측 상위 k와 실제 상위 k가 겹치는 비율
- **x2 / x4**: 예측 상위 2k·4k로 넓게 잡았을 때 실제 상위 k가 들어오는 비율 — *후보 생성* 관점의 지표

## 결과

### 1. 니케 단위 — 잘 맞는다 (k = 25)

| 예측 | topk | x2 (50명) | x4 (100명) | x2 최악 시즌 |
|---|---|---|---|---|
| 직전 시즌 | 0.70 | 0.85 | 0.85 | 0.64 |
| 최근 3시즌 평균 | 0.71 | 0.86 | 0.90 | 0.68 |
| **혼합** | **0.74** | **0.90** | **0.92** | **0.80** |

- 과거 기반 상위 50명 안에 이번 시즌 주력 25명 중 평균 **90%**(최악 80%)가 들어온다.
- 못 잡는 몫의 대부분은 **신캐**다. 과거에 한 번도 안 쓰인 니케가 매 시즌(37/37) 슬롯의 평균 6.8%,
  최대 12%를 차지한다. 신캐는 사전 지식에 없으니 **무조건 후보에 넣는 규칙**이 필요하다.
- 약점 속성이 직전과 같으면 훨씬 잘 맞는다(topk 0.88, 표본 2회뿐). 속성 정보를 섞은 혼합이 가장 좋다.

### 2. 같은 덱 짝 — 잘 안 맞는다 (k = 100쌍)

| 예측 | topk | x2 (200쌍) | x4 (400쌍) | x4 최악 시즌 |
|---|---|---|---|---|
| 직전 시즌 | 0.34 | 0.47 | 0.57 | 0.21 |
| 최근 3시즌 평균 | 0.36 | 0.51 | 0.65 | 0.33 |
| **혼합** | **0.42** | **0.56** | **0.69** | **0.50** |

- 누가 쓰이는지는 이어지지만, **누구와 누가 같이 서는지는 보스마다 크게 바뀐다.** 400쌍으로 넓혀도 70%.
- 순위 상관(Spearman)은 보고하지 않는다. 양쪽 상위권의 합집합에서 재면 겹침이 적을 때 구조적으로
  음수가 나와 해석할 수 없다.

### 3. 5인 구성 — 과거 덱의 "한 명 교체" 이웃이 대부분을 덮는다

| 시즌 t의 덱 중 | 평균 | 최소 | 최대 |
|---|---|---|---|
| 과거 어느 시즌 덱과 **5명 모두** 같은 비율 | 0.41 | 0.01 | 0.77 |
| 과거 어느 시즌 덱과 **4명 이상** 같은 비율 | **0.76** | 0.43 | 1.00 |
| ─ 그중 1덱(최고 딜) | 0.70 | 0.01 | 1.00 |
| ─ 그중 5덱(최저 딜) | 0.77 | 0.33 | 1.00 |
| 서로 다른 스쿼드 수 / 시즌 (약 1,470덱 중) | 133 | 40 | 310 |
| 상위 10개 스쿼드가 차지하는 비율 | 0.73 | 0.51 | 0.95 |

- 랭커는 강하게 수렴한다(시즌당 실질 스쿼드 약 130개, 상위 10개가 73%).
- "과거 랭커 스쿼드 + 한 명 교체"라는 이웃이 이번 시즌 덱의 약 3/4을 덮는다.
- 1덱이 오히려 새롭다: 신캐가 가장 먼저 들어가는 자리라서다(최소 0.01 = 신캐가 1덱을 갈아엎은 시즌).

### 4. 버스트 구성 — 틀은 몇 개로 정해져 있다

| I-II-III 인원 | 평균 | 최소 | 최대 |
|---|---|---|---|
| 1-1-3 | 0.40 | 0.15 | 0.71 |
| 1-2-2 | 0.24 | 0 | 0.61 |
| 2-1-2 | 0.22 | 0 | 0.41 |
| 1-1-2 + 전 단계(X) | 0.06 | 0 | 0.20 |
| 2-1-1 + X | 0.04 | 0 | 0.20 |
| 0-1-4 | 0.02 | 0 | 0.19 |

상위 3개 틀이 86%, X 포함 5개가 96%. 어느 틀이 우세한지는 시즌마다 크게 흔들린다.

## 해석과 한계

- 이 데이터가 재는 것은 **"랭커가 무엇을 쓰나"**다. 최적성의 대리 지표일 뿐이다. 랭커 수렴에는 모방도 섞여 있고,
  랭커는 대부분의 니케를 보유하고 육성한 계정이다.
- 짝이 잘 안 맞는 이유는 보스 의존성과, 조합 수가 많아 원래 잡음이 큰 것이 섞여 있다. 둘을 가르지는 않았다.

## nikke-opt에 주는 결론

| 층 | 사전 지식을 믿어도 되나 | 설계 반영 |
|---|---|---|
| 니케 | **믿는다** | 혼합 예측 상위 약 50명 + **신캐 전원**을 핵심 풀로. 나머지는 낮은 우선순위(버리지는 않음) |
| 5인 구성 | **출발점으로 믿는다** | 과거 랭커 스쿼드(최근·같은 속성 가중) + 한 명 교체 이웃을 첫 후보군으로 (≈ 3/4 커버) |
| 짝 | **약하게만** | 대리 모델의 짝 항은 이번 보스 시뮬 결과로 배워야 한다. 과거 짝은 약한 사전값 정도 |
| 버스트 틀 | 틀 목록은 믿되 비중은 안 믿는다 | 5개 틀을 구조 필터로(부드럽게). 어느 틀이 좋은지는 시뮬이 정한다 |

작은 예산(~10회) 구간에서는 사전 지식이 답을 내야 하는데, 니케·구성 단위로는 그만한 정보가 있다.
반대로 "누구와 누구를 붙일지"는 시뮬레이션이 가장 필요한 부분이다 — 탐색 예산은 여기에 쓰인다.
