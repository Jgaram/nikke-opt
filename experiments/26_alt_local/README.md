# 실험 26 — θ = 0.2 대안 근처 짧은 탐색: 대안 쪽에 1,000평가를 더하면 97%에 닿는가

> 실험 24에서 계정 탐색 기록의 J ≤ 0.2 대안은 최선의 96.4%(12개 중 5개만 97% 이상)였다.
> 대안 덱은 기록 안의 이웃이 중앙 19개로, 최선 덱(291개)보다 훨씬 덜 탐색된 덱이었다.
> **그 대안 근처를 짧게 더 탐색하면 97%에 닿는가? 같은 예산을 평소 탐색에 더 쓰는 것보다 나은가?**

**상태: 계획 · 판단 기준 사전 등록(2026-11-01, 결과 전).**
- 출처: 2026-11-01 사용자 결정 「(다)로 진행」. 실험 24 결정 후보 (나)다. (가)는 [실험 25](../25_jpick_alt/README.md)다.
- 사용자 지시: 주력 딜러 개념은 쓰지 않는다.

## 조건

- **평가기 · 보스 · 운용:** [실험 20](../20_search_robust/README.md)과 같다. Rust `nikke-sim`(nikke-calc-rs `89d2e64`)이고, 기록의 구성을 다시 평가하면 같은 값이 나온다(4개 확인).
- **계정:** 실험 20 개발 계정 12개(d1~d4 · t1~t8). 실험 24와 같은 계정이다.
  개발 계정이라 여기서 정한 예산 · 방식은 나중에 새 계정에서 다시 잰다.
- **값:** 기본 레이어 180초 딜이다. 후처리는 하지 않는다(실험 24와 같은 비교).

## 절차

[`run26.py`](run26.py).

1. **출발:** 계정 탐색 기록 `U4_3000`(실험 24와 같은 기록)을 세션에 넣는다(시뮬 없음).
   기록의 최선 5덱과 J ≤ 0.2인 5덱 중 합 최대가 출발 대안이다(실험 24 값과 같아야 한다).
2. **대안 쪽 탐색 1,000평가:**
   - 875평가는 라운드(100평가)로 돈다. 라운드마다 그때 기록에서 다시 고른 J ≤ 0.2 대안 5덱을 고친다.
     - **5덱 고치기 70%:** 한 명 바꾸기 · 두 덱 사이 맞교환. 실험 4 `pack_moves`이고, 실험 5 이후 국소 탐색과 같은 수다.
     - **대안 덱의 이웃 30%:** 안 쓴 니케로 한 명 바꾸기.
     - 고친 뒤 5덱도 최선과 J ≤ 0.2여야 한다. 순서는 대리 모델(실험 10 `DualFit`)의 예상 이득 순이다.
   - 끝 125평가는 마지막 대안 덱의 배치 순서 다듬기다(`distinct_orders`, 실험 10과 같다).
   - +500에서 한 번 기록한다(관찰).
3. **대조(시뮬 없음):** 같은 계정의 계정 탐색 `U4_4000` 기록이다. 평소 탐색에 1,000평가를 더 쓴 기록이고, 같은 고르기를 한다.
4. **값 비율:** 대안 합 ÷ 같은 기록의 최선 합이다. 최선이 바뀌면 J도 새 최선 기준으로 다시 고른다.
   J 상한 묶기가 120초를 넘으면 찾은 해를 쓰고 표시한다.

## 판단 기준 (사전 등록 — 결과 전)

+1,000 뒤의 값 비율로 판단한다.

| 판단 | 조건 |
|---|---|
| **짧은 탐색으로 충분** | 중앙 ≥ 97% **그리고** 12개 중 9개 이상이 97% 이상 |
| **더 큰 보강 필요** | 중앙 < 95%(또는 대안이 없는 계정이 있음) |
| **일부** | 그 사이 |

- **대조와 비교:** +1,000 중앙이 대조(U4_4000) 중앙보다 0.5%p 이상 높으면 「대조보다 앞섬」, 아니면 「대조와 비슷하거나 뒤짐」을 판단에 붙인다.
  앞서지 못하면, 대안 쪽으로 겨눈 탐색이 평소 탐색보다 낫다고 말하지 않는다.
- **관찰:** +500 값, 새 대안 덱의 이웃 수 변화, 대안의 J · 바꿀 · 공유, 최선이 바뀐 계정.
- 실험 24의 해석 기준(97% · 95% · 3/4)과 같은 문턱이다.

## 예산과 실행

- 새 시뮬은 계정마다 1,000 이하, 12개 합 12,000 이하다. 대조는 시뮬 0이다.
- J 상한 묶기는 첫 번째만 오래 걸린다. 그다음부터는 직전 대안의 합을 하한으로 넘겨 빠르다(결과 같음, 확인함).
- 실행은 `run`(계정 셋씩 프로세스 4개), `analyze` 순서다.
