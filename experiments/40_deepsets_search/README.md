# 실험 40 — Deep Sets 대리 모델을 탐색에 붙이기

> 실험 34: Deep Sets(G3)가 덱 순위를 지금 릿지보다 잘 맞힌다(상위 10% 안 0.817 대 0.705, 니케 가리기 3/4). 다만 12만 관측으로 학습한 값이다.
> 실험 38: 사전 계산 탐색이 막히는 곳은 「다음에 무엇을 계산할지 고르기」이고, 릿지는 아직 안 본 랭커 덱을 실제의 중앙 74%로 본다
> (다른 시드가 찾은 고득점 구성은 89%). Deep Sets가 **탐색 안의 자료 크기(1천~1만 평가)에서도** 릿지보다 낫고, 그 간극을 줄이는가?

**상태: 1단계 사전 등록(실행 전, 2026-11-03).** 진행 방식은 [연구 회차](../../docs/SEARCH.md#연구-회차-계획--실험--해석--다음-방향-결정)를 따른다.

## 왜 이것인가

- 사전 계산 · 계정 탐색은 같은 탐색 코드(실험 10 `run_method`)다. 라운드(100평가)마다 그 세션 기록만으로 릿지(`DualFit`)를 다시 맞춰
  ⓐ 최선 5덱 고치기 · ⓑ 값 상위 40 구성의 한 명 교체 이웃을 예측 순으로 고른다. 실험 34처럼 12만 관측이 아니다.
- 실험 38 ③ 재생 틀(실험 36 기록을 순서대로 다시 쌓고 모델 시점마다 다시 맞추기)이 있어 시뮬 없이 같은 시점 · 같은 자료로 견줄 수 있다.
- 실험 39 판 b: 릿지의 근사 불확실성은 잔차와 상관이 없었다(−0.02~−0.20). Deep Sets 그물 3개의 예측 퍼짐이 쓸모 있는지 함께 본다(관찰).

## 1단계 — 시뮬 0, 실험 36 기록 재생

- 자료: 실험 36 `run_log/S??/B_s0 · B_s1`(S33~S42, 평가기 nikke-calc-rs `8bc51a2`, 코어 없음, 사전 값), 랭커 덱 값 `rankers.json`,
  실험 38 `visit/`(방문 범주). 미리 학습 자료 = 실험 33 P + 넣어 보기(121,373관측, 같은 평가기, 177명 전원 · 속성 5개).
- 시점: 시드마다 1,000 · 3,000 · 6,000 · 9,000평가(실험 38 `FIT_AT`, 순서 다듬기 전만). 그때까지의 기록(구성마다 최고 값)으로 모델을 맞춘다.
- 모델(시점마다 같은 자료):

| 키 | 모델 | 학습 |
|---|---|---|
| R0 | 지금 릿지 `DualFit`(니케 + 짝, 원 값) | 실험 38과 같다 — 재현 확인용 |
| D1 | Deep Sets — 실험 34 G3 고른 설정(d 32 · 은닉 128 · wd 0 · lr 1e-3 · 배치 512 · 그물 3개) | 세션 기록만. 기록의 10%(난수 고정)를 떼어 조기 종료(최대 400에포크 · 참을성 15), 가장 좋던 가중치 |
| D2 | 같은 그물을 실험 33 자료로 미리 학습(58에포크 = 실험 34가 고른 값) | D1과 같은 90% · 10%로 이어 학습(lr 3e-4, 같은 조기 종료). 정규화는 미리 학습 것 |
| D2_0 | 미리 학습만 | 관찰 — 이어 학습 없이 시즌 계정에 얼마나 맞나 |

- 지표(시점마다, 실험 38과 같은 정의):
  - **간극** = 다른 시드 고득점 구성(이 시드가 아직 안 본 값 상위 300)의 예측÷실제 중앙 − 아직 안 본 랭커 덱 예측÷실제(사용 수 가중 중앙,
    실험 38처럼 끝까지 어느 시드도 계산하지 않은 V5 밖 덱만). 시즌 값 = 두 시드 · 모든 시점을 합쳐 실험 38 방식으로 모은 값. 작을수록 랭커 덱을 덜 낮게 본다.
  - **다음 500 순위 상관** = 시점 바로 뒤에 실제로 처음 계산한 구성 500개의 스피어만 ρ(시즌 값 = 셀 중앙). 탐색이 실제로 묻는 곳의 일반 정확도.
  - 관찰: 다음 500의 상위 10% 안 ρ · 상위 10 적중, 고득점 300의 ρ · 그 예측이 모델의 기록 상위 40 예측 이상인 비율, 랭커 덱 예측이 상위 40 이상인 비율
    (실험 38 릿지 0%), 예측÷실제 중앙, 퍼짐 ↔ |log 잔차| 순위 상관(D만), 맞추기 초.

## 사전 등록 (2026-11-03, 재생 실행 전)

시즌마다 D − R0 차이를 내고 10시즌 중앙으로 본다. D1 · D2를 따로 판단한다.

| 줄 | 조건 | 다음 |
|---|---|---|
| 1 | 간극 차이 중앙 ≤ −5%p **그리고** 다음 500 ρ 차이 중앙 ≥ −0.02 | **2단계(시뮬) 후보** — 실험 39 틀에 판으로 끼워 S23~S32에서 base와 비교 |
| 2 | (1 아님) 다음 500 ρ 차이 중앙 ≥ +0.05 | 일반 예측만 나음 — 시뮬로 갈지 사용자 판단 |
| 3 | (1 아님) 간극 차이 중앙 ≤ −5%p, ρ는 −0.02 밑 | 랭커 덱만 — 사용자 판단 |
| 4 | 그 밖 | 중단 — 탐색 안 자료 크기에서는 릿지와 같거나 못함 |

- 둘 다 1줄이면 2단계는 간극을 더 줄인 쪽, 차이가 1%p 안이면 D1(외부 자료 없음).
- 재현 확인: R0의 시즌별 랭커 덱 비 · 고득점 비가 실험 38 `analysis.json`과 같아야 한다(같은 코드 경로). 다르면 판단 전에 원인을 적는다.
- 판단은 `an40.py analyze`가 계산한다(`GAP_WIN` · `RHO_FLAT` · `RHO_WIN` · `TIE`).

## 2단계 계획(1단계가 1줄일 때만, 따로 사전 등록)

- 실험 39 틀에 판 하나(`fitf` = 고른 Deep Sets)를 더해 검증 시즌 S23~S32, 두 시드 × 12,500평가. base는 실험 39 기준선 기록을 그대로 쓴다.
- 판정은 실험 39와 같은 표(r 시즌 중앙 ≥ +0.5% 그리고 r < −1% 시즌 ≤ 1이면 좋음).
- 학습 비용: 1단계 맞추기 초로 정한다(라운드마다 다시 맞추면 시드 하나에 학습만 1~2시간 — 몇 라운드마다 · 이어 학습 중 고른다).
- 시뮬은 평가기가 필요하다. 이 컨테이너에는 없다(실험 39 SESSIONS: 작업 세션은 평가기 붙이기가 자동 권한 검사에 막힘) — 어디서 돌릴지 사용자 확인.

## 한계 (미리 적음)

- 다음 500은 릿지가 고른 구성이다(릿지가 높게 본 곳). 두 모델을 같은 묶음에서 견주지만, 모델이 고르지 않은 구성의 정확도는 고득점 300 · 랭커 덱으로만 본다.
- S33~S42는 실험 38 · 39 개발에 쓴 시즌이다. 1단계는 개발용 점검이고, 효과 검증은 2단계(S23~S32)에서만 한다.
- 시점 사이 모델 변화(라운드마다 다시 맞추기)는 보지 않는다. 시점마다 처음부터(D1) · 미리 학습에서(D2) 맞춘다.
- 미리 학습 자료(실험 33)는 177명 전원 보유 · 상, 기본 레이어다. 시즌 계정은 그 시즌 풀 · 그때 없던 애장품 0단계라 값이 조금 다르다.
