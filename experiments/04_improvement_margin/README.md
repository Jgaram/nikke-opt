# 사전 실험 4 — 개선 여지

> 같은 육성·같은 보스에서 시뮬로 찾은 최선 5덱이 **랭커 구성 기준선**보다 얼마나 나은가?
> 시뮬 성능 개선의 가능성을 재는 실험이다.

현재 목표는 [뼈대가 다른 후보군과 큐브·컨트롤 공동 탐색, 임의 보스 패턴 대응](../../docs/GOALS.md#문제-정의)이다.
이 실험은 정해진 보스·운용에서 단일 최고 5덱을 개선하는 기준선이다. 아래 결과는 그대로 보존하며,
새 목표에 대한 실험은 아직 하지 않았다.

## 조건

| | |
|---|---|
| 평가기·보스·육성·풀 | [실험 2](../02_score_distribution/README.md)와 같다 (nikke-calc `ba9f29c`, S40, 전원 기본 스펙, 풀 60명) |
| 출발 | 실험 2에서 평가한 2,082개 스쿼드(무작위 1,500 · 랭커 224 · 순서 전수) |
| 이번 예산 | **평가 801회** (180초 시뮬) |
| 재현 | `NIKKE_CALC_DIR=<nikke-calc> python search.py` (실험 2를 먼저 돌린다) — 어댑터가 요청 v2를 보내므로 nikke-calc `167698c` 이후가 필요하다(실험 당시 `ba9f29c`와 딜이 같음을 표본 12개로 확인, 2026-10-08) |
| 원출력 | [`results.md`](results.md), [`summary.json`](summary.json), [`log.jsonl`](log.jsonl) (이번에 돌린 스쿼드 전부) |

탐색기는 실험 2·3의 결론대로 만든 축소판이다 ([`search.py`](search.py)).

1. **이웃** 3라운드 × 150 — 평가한 상위 40개 구성마다 한 명 교체(같은 버스트 단계끼리) 이웃을 만들고,
   지금까지의 모든 결과로 학습한 「니케 + 짝」 릿지 모델의 예측 상위만 돌린다.
2. **덱 단위 개선** 3라운드 × 100 — 지금 최선 5덱에서 ① 한 덱의 한 명을 *다른 네 덱이 안 쓰는* 니케로 바꾸거나
   ② 두 덱이 같은 단계 니케를 맞바꾸는 수를, 모델의 예상 이득 순으로 돌린다.
3. **순서 다듬기** — 상위 20개 구성과 최선 5덱의 「딜이 달라질 수 있는」 배치 순서 전부.
4. **조립** — 평가한 모든 구성(구성마다 최선 순서)에서 겹치지 않는 5개를 분기 한정으로 정확히 고른다.

### 관찰

1. **상위 구성 근처만 파면 5덱 합이 늘지 않는다.** 이웃 라운드(411회)에서 1덱보다 강한 스쿼드(94.6, 순서 다듬기 후 95.7)를
   찾았지만 5덱 합은 그대로였다. 강한 스쿼드는 다른 덱의 핵심 니케(미하라·마스트)를 빼 와서 만든 것이라 조립에서 겹친다.
   [목표 문서](../../docs/GOALS.md#배경)의 「승부는 대체 자원을 3~5덱에 어떻게 나눠 쓰느냐」가 그대로 나타났다.
2. **5덱을 함께 보는 수(덱 단위 개선)만 합을 올렸다.** 300회로 +1.0억, 순서 다듬기로 +0.3억 더.
3. **이 조건과 탐색 범위에서 랭커 기준선 대비 개선은 작았다.** 같은 기본 스펙이면 랭커 300명의 5덱 시뮬 합 중앙값이 306.4억,
   최고가 309.3억이고, 801회 탐색으로 찾은 개선은 +0.5%다. 더 좋은 다른 뼈대가 없거나 전역 최적에 가깝다는 증거는 아니다.

## 해석과 한계

- **기준선이 유리한 조건이다.** 전원 보유·전원 같은 육성, 그리고 랭커가 이미 한 달 공략한 보스(S40)다. 이 레포가 겨냥하는
  상황 — 일부 니케가 없거나 육성이 고르지 않은 계정, 랭커 기록이 아직 없는 새 보스·신캐 — 에서는 랭커 구성을
  「옮기는」 것만으로 최적이 아니다([목표 문서의 배경](../../docs/GOALS.md#배경)). 그 조건의 개선 여지는 이 실험이 재지 않았다.
- **하한이다.** 국소 탐색 801회, 이웃은 같은 단계 한 명 교체와 두 덱 맞교환뿐이다(틀 바꾸기·세 덱 순환 없음).
- 유력 군집의 수·누락·안정성을 재지 않았다. 큐브·컨트롤은 고정 조건이며, 바꾸었을 때 살아나는 조합은 미검증이다.
- 풀에 S40 랭커 정보가 샌다(실험 2와 같음). 이번 보스의 랭커 정보가 없는 새 패턴 적응 성능으로 해석할 수 없다.
- 이것은 시뮬딜 기준이다. 랭커의 실제 딜·육성과는 비교하지 않는다.

## nikke-opt에 주는 결론

| | 설계 반영 |
|---|---|
| 탐색 단위는 **5덱 묶음** | 「좋은 스쿼드 찾기」와 「조립」을 따로 돌리지 않는다. 지금 최선 5덱을 기준으로, 다른 덱이 안 쓰는 니케 교체·덱 간 맞교환처럼 **조립 결과를 바꾸는 수**를 대리 모델의 *예상 이득*으로 고른다 |
| 정수계획 조립은 매 라운드 | 분기 한정(수천 개 구성에서 1ms 미만)으로 충분하다. 외부 솔버는 아직 필요 없다 |
| 랭커 구성은 강한 출발점 | 이 조건에서 높은 기준선이었다. 작은 예산의 출발점으로 활용하되, 다른 뼈대의 필요성을 배제하지 않음 |
