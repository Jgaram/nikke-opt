- 판정 결과: O × (800 −0.6% · 2,000 −0.7%, 둘 다 −3% 밑 1개) → I1 × (2,000 −0.5% 못하다) → I2 ○ → 「이어 붙이기로 충분(I2)」.
  README 사전 등록대로 「C5에서 O가 통과하지 않음 = 메타 밖 신캐도 갱신 필요(예상과 다름)」으로 적는다.
- 다만 새 니케는 어떤 판 · 계정 최종 5덱에도 0명이다(O · I1 · I2 · F4 모두, 보유 · 미보유 모두). O의 차이는 신캐 편입이 아니라
  구 풀 사전 계산 시드 4개 자체의 결과 차이로 보인다 — 시드 s0 · s2가 뼈대를 놓쳤고(191.8 · 195.0), 합친 O 최선 5덱 202.4는 F4 U4 쪽 근사(203.7)보다 낮다.
