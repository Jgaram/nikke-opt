# 실험 43 — 구조 규칙 없는 탐색 + 카메라 다듬기를 검증 시즌에서 지금 절차와 비교

> 실험 42에서 구조 규칙은 개발 시즌 OPT를 막지 않았고(판단 1: 0/3), 규칙을 빼도(판 R) 기본 값 세계 탐색이 나빠지지 않았다(99% 도달 10/12 대 base 9/12).
> 순서는 「단계 안 순서 × 카메라」로 확정됐고, 지금 절차(base)의 검증 시즌 최종 5덱에 카메라 고르기를 얹으면 5덱 합이 중앙 +0.28% 올랐다.
> 이 실험은 규칙을 뺀 탐색이 **실제 시뮬 · 전체 풀(123~150명)**에서도 손해가 없는지 검증 시즌 S23~S32에서 잰다. 손해가 없으면 규칙(라피 : 레드 후드 예외 같은 특정 니케 하드코딩)을 지금 절차에서 빼고 카메라 다듬기를 넣을 근거가 된다.

**상태: 끝(2026-11-05) — 판단 1 나쁨 → 구조 규칙 유지. 판단 3 → 카메라 다듬기 채택 후보(지금 절차를 바꿀지 사용자 확인).** 계획(사전 등록)은 `8be1b57`에 결과 전 고정했다. 사용자 결정(2026-11-05): 실험 42 다음 회차 「규칙 없음 + 카메라 검증」(추천안). 판단 수치는 실험 42 판단 3(사용자 확정)과 같다.
진행 방식은 [연구 회차](../../docs/SEARCH.md#연구-회차-계획--실험--해석--다음-방향-결정)를 따른다.

## 판단 기준 (사전 등록 — 실행 전)

r = R ÷ base − 1(시즌마다). 판정 수치는 실험 39 · 42 판단 3과 같다: **좋음** r 시즌 중앙 ≥ +0.5% 그리고 r < −1%인 시즌 ≤ 1 · **나쁨** r 시즌 중앙 ≤ −0.5% 또는 r < −1%인 시즌 ≥ 3 · **비김** 그 밖.

| # | 무엇 | 비교 | 읽기 |
|---|---|---|---|
| 1 | 규칙 빼기(Q1, 주 판정) | 카메라 다듬기 **뒤** 값끼리(base 다듬은 뒤 대 R 다듬은 뒤) | **좋음 · 비김 → 규칙 빼기 채택 후보**(손해 없음 — 하드코딩을 없앨 근거, 지금 절차를 바꿀지 사용자 확인). **나쁨 → 규칙 유지**, 진 시즌의 덱 · 니케를 적는다 |

- 함께 보는 것(판정에 안 씀): 묶음 전체 이득(R 다듬은 뒤 ÷ base 다듬기 전 − 1 — 지금 절차를 두 가지 다 바꿨을 때), 놓친 몫 G · 랭커 덱 방문(실험 38 · 39), 규칙 밖 덱이 요청 · 최종 5덱에 든 수, 시드 잡음(실험 39 base 1.86%), 계산 시간.

### 관찰과 원인 가설

- **규칙 밖 덱은 약하지 않다(관찰).** R 기록의 값 상위 100구성 중 규칙 밖이 6 ~ 44개, 규칙 밖 최고 덱이 규칙 안 최고 덱보다 센 시즌이 10시즌 중 6(+1.1 ~ +7.3%).
  예: S26 1단계 없는 마스트 : 로망틱 메이드 · 크라운 · 이브 · 헬름 · 라피 : 레드 후드 60.3억(base 최고 덱 45.9억). 규칙은 센 덱을 막고 있다.
- **그런데 5덱 합은 낮다(관찰).** S25 · S26에서 R은 센 니케를 덱 하나에 몰고 다섯째 덱이 약하다(S25 22.2억 대 base 28.7억). base 5덱을 R은 S25에서 1/5, S26에서 3/5만 쟀다.
- **가설(미확인):** 규칙(1 · 2 · 3단계 각 1명 이상)은 덱 하나의 제약이 아니라 **묶음 수준의 사전 지식**으로 작동한다 — 1단계 니케를 다섯 덱에 나눠 주고, 구성 단계(설계 · 탐욕 구성)가 균형 잡힌 다섯 덱을 처음부터 만든다.
  규칙을 빼면 같은 예산에서 센 덱 하나를 쫓고 묶음을 덜 맞춘다. 개발 시즌(40명 풀)에서는 이 차이가 안 보였다(실험 42 R 10/12 대 base 9/12) — 풀이 작아 니케가 모자라지 않았기 때문일 수 있다.
